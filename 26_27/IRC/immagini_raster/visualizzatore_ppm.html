Visualizzatore e modificatore PBM/PPM

Apri un file P1 PBM o P3 PPM. Il riquadro a sinistra mostra i pixel ingranditi, quello a destra mostra i numeri che li codificano.

Apri uno dei file presenti nella cartella file_sorgente.

Fai clic su un pixel per modificarlo. Nei file PBM il clic alterna bianco e nero. Nei file PPM usa il selettore del colore.
